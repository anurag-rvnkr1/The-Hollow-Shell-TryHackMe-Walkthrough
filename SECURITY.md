# Security Policy

This repository contains documentation for an intentionally vulnerable TryHackMe lab. It does not provide a production service.

## Scope

The techniques discussed here are limited to authorized training environments. Do not use the documented commands against systems without explicit permission.

## Reporting

Because this repository is a static educational write-up, security reports about the documented vulnerability should be directed to the challenge platform rather than treated as a live application disclosure.

## Publication policy

The final TryHackMe flag is intentionally redacted from public documentation and screenshots.
