# Contributing

Thanks for helping improve this CTF documentation.

## Standards

- Keep write-ups original and explanatory.
- Do not publish challenge flags in new screenshots or examples.
- Use sanitized placeholders such as `TARGET_IP` and `YOUR_ATTACKER_IP` in reusable code.
- Prefer harmless validation steps before active payload execution.
- Keep image filenames numbered and aligned with the documentation sequence.

## Documentation changes

Markdown lives in `Documentation/`, `docs/`, and `Resources/`. Generated evidence images belong in `docs/assets/`. Word output is maintained as `Documentation/Documentation.docx`.
